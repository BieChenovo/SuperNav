## 重评分与核验

- 原公开数据文件与评分器没有修改。公开评分器将阈值写死为 0.1 米；另外实现了参数明确的离线评分器，以 1 米重评保存轨迹。
- 单目标：最终位置到全部批准观察点的最短 NavMesh 测地距离严格小于阈值，并且存在显式 STOP。
- 多目标：按照保存轨迹检查顺序到达，要求显式 STOP；起点可以满足目标，同一位置可以满足连续目标，不对保存位置之间插值。
- SPL 使用同一数据集的 global_shortest 参考长度和完整实际路径长度。
- 新评分器在 0.1 米下与公开评分器以及既有结果逐条一致：400/400。另检查阈值边界、缺失 STOP、重叠目标、访问顺序、禁止插值和单目标终点判定。
- 评测地图、批准观察点和距离曲线只用于离线审查，未反馈给导航 Agent。尚未执行的任务不作为失败加入 SR 分母。

数据版本 `yyh929/HabitatGS-Benchmark@4f4f96921dfe4f8e8f720422c5a3d3e5fd70ee57`；选集 seed 42。`verification.json` 保存校验摘要；`episodes.csv` 保存全部 400 条记录在两种阈值下的评分；`comparison.json` 保存配对清单与汇总；`score_and_export.py` 保存评分实现。
